# Requested visual genealogy workflows

These are additions to the unchanged Ideas.md, not a replacement for it.

| Request | Implemented interface |
| --- | --- |
| MyHeritage / MacFamilyTree-inspired interaction, without dependency | Original local-first family workspace, readable chart cards, person inspector and explicit evidence. No copied branding or provider connection. |
| Event symbols and colour | 35 built-in event types with colour-coded symbols and a readable legend; custom events receive a neutral fallback. |
| Relationship line types, symbols and colour | 35 relationship types including dating, engaged, married/spouse, separated, divorced, annulled, widowed, former partner, sibling, half/step siblings, cousin, immediate/extended family, and biological/adoptive/foster/step parents. |
| Biological, adoptive and foster roles | Explicit mother/father/parent and sibling types; no inference from photographs or gender. |
| Individual profile pictures | Upload, choose existing archive image, change and remove; originals retained in Media studio; thumbnails included in full backups. |
| Blind/deaf and single-parent symbols | Optional, private, user-entered badges. Sharing-safe exports omit them; chart badges require an explicit display choice. |
| Different family views | Family tree, genealogy/pedigree, descendants, hourglass, wedge fan and a separate searchable people page. |
| Click a person; Show more for details | Compact on-chart overview with photo/name/vitals/place/close family; expandable biography, events/evidence, relationships and facts. |

Colours never replace labels or line patterns. Status changes are explicit edits, not automatic interpretations of life events. A fan supports two recorded parents per branch; the Family view retains additional parent links. It is not proof of biological ancestry.

Profile pictures have not been invented for the user's relatives. Initials remain until a photo is supplied. Test-browser data is separate from the published user's archive.

Full backups preserve all application fields; limited GEDCOM export cannot preserve every specialised relationship type, media link or private badge. See RELEASE_NOTES.md and VALIDATION.md for remaining limitations.
